# Sofabeam releases

Android app releases for [Sofabeam](https://sofabeam.com), for Fire TV, Firestick, Android TV, Google TV, and Android phones and tablets.

## Install

On a TV, open **Downloader** and enter `sofabeam.com/apk`. That address always points to the latest `sofabeam.apk` here. Step-by-step instructions for each device are at [sofabeam.com/download](https://sofabeam.com/download).

After installing, open Sofabeam and select **Connect my TV**, then scan the QR code with your phone to pair it with your account.

Upgrading from the old **Relay TV** app? Uninstall Relay TV first, then install Sofabeam and pair your TV again.

## About

Sofabeam works with an IPTV subscription you already have. It does not include, sell or provide any channels, streams or subscriptions, and it is not affiliated with any provider.
